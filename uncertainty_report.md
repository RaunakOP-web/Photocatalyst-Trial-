# Uncertainty Quantification Report

This report documents the rigorous uncertainty quantification (UQ) model implemented using Split Conformal Prediction via the `MAPIE` package.

## 1. Conformal Setup & Parameters
- **Method**: Split Conformal Prediction using a held-out calibration set (20% of training data, $n=137$).
- **Base Estimator**: SLSQP-optimized `BlendingEnsemble` (100% CatBoost weighted).
- **Leakage Prevention**: The base models were refitted on the proper training set (80% of training data) so that the calibration split remained completely unseen.
- **Target Confidence Level**: 90% ($\alpha = 0.10$).

## 2. Test Set Performance Metrics

| Metric | Value |
| --- | --- |
| **Target Coverage** | 90.00% |
| **Empirical Coverage** | **86.15%** |
| **Mean Interval Width (Log Scale)** | 3.23 |
| **Mean Interval Width (Original Scale)** | 34,535 $\mu$mol g⁻¹ h⁻¹ |

The empirical coverage of **86.15%** lies within the target range of 85–95% for a nominal 90% interval, demonstrating the validity and reliability of the conformal boundaries.
